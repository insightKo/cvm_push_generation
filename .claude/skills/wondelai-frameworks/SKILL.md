# Wondelai Frameworks — фреймворки для копирайта (Дикси-CVM)

## Когда применять
- Структура текста не очевидна (особенно для контентных акций)
- Нужен второй / третий вариант под тот же оффер
- Нужно объяснить пользователю, почему выбран именно такой текст
- Длинный формат (>100 символов): описание акции, e-mail, карточка

> Короткий хук (≤30 символов) → [[hook-generator]] (там паттерны, а не фреймворки).
> Голос/лексика → [[voice-builder-dixy]].

## Фреймворк 1 — AIDA (Attention → Interest → Desire → Action)

Для **e-mail / длинных описаний акций.**

```
[A] Цепляющий первый экран (цифра / личное)
[I] Раскрытие выгоды (что именно и почему хорошо)
[D] Срочность / ограничение / соц. доказательство
[A] CTA — что делать сейчас
```

Пример (e-mail):
> [A] Минус 30% на курицу до воскресенья
> [I] Охлаждённая Петелинка 1кг — 199₽ вместо 285₽. На все позиции категории.
> [D] Акция до 7 апреля. На прошлой неделе разобрали 12 000 упаковок.
> [A] Откройте купон в приложении и предъявите на кассе.

## Фреймворк 2 — PAS (Problem → Agitate → Solution)

Для **реактивации Спящих/Оттока** — нужен повод вернуться, а не выгода.

```
[P] Проблема клиента (мягко, без обвинений)
[A] Развитие проблемы (без давления)
[S] Решение от Дикси (конкретное)
```

Пример (push body):
> [P] Давно не заходили?
> [A] Любимые позиции могут пропасть с акции.
> [S] +200 монет к первому чеку этой недели.

## Фреймворк 3 — FAB (Feature → Advantage → Benefit)

Для **описаний рецептных и категорийных акций** — когда нужно объяснить, чем эта SKU/набор лучше.

```
[F] Что это (фактически)
[A] Чем отличается (от обычного)
[B] Что это даёт клиенту (выгода)
```

Пример:
> [F] Набор для борща: говядина, свёкла, морковь, лук, картофель.
> [A] Подобрано на 4 порции, всё свежее с одной полки.
> [B] Минус 20% к стоимости отдельных SKU. Ужин за 15 минут.

## Фреймворк 4 — BAB (Before → After → Bridge)

Для **контентных кампаний** (рецептные, сезонные, лайфстайл).

```
[B] Как было (без акции)
[A] Как станет (с акцией)
[B] Мост — как перейти (механика)
```

Пример (карточка контентной акции «Завтрак за 5 минут»):
> [Before] Утром не успеваете готовить — едите бутерброд.
> [After] Готовая гранола, йогурт, ягоды — завтрак за 5 минут.
> [Bridge] Купон −25% на набор «Завтрак» в приложении до пятницы.

## Фреймворк 5 — 4U (Useful, Urgent, Unique, Ultra-specific)

Для **заголовков купонов и push title**, когда нужен максимум плотности.

```
Useful        → есть конкретная польза
Urgent        → есть дедлайн
Unique        → отличает от соседних акций
Ultra-specific → цифра + категория, не общее
```

Чек-вопросы:
- Польза очевидна за 1 секунду? (Useful)
- Понятно, когда сгорит? (Urgent)
- Не похоже на ещё 5 пушей этой недели? (Unique)
- Есть цифра и конкретная категория? (Ultra-specific)

Пример:
> ❌ `Выгодные предложения на этой неделе`
> ✅ `Курица охлаждённая −30% до воскресенья` ← все 4U есть

## Фреймворк 6 — Jobs-to-be-Done (для сегментации контентных акций)

Для **выбора темы контентной акции**: какую «работу» клиент нанимает Дикси сделать.

| Job | Тема контентной акции | Кому |
|---|---|---|
| «Накормить семью в будни» | Готовые наборы для ужина | Мамы, Активные с детьми |
| «Закрыть выходные» | Набор для пикника / шашлыка | Активные, дачники |
| «Сэкономить, но не на еде» | СТМ-альтернативы по категориям | Низкие сегменты, Случайные |
| «Угостить гостей» | Сырные/мясные тарелки, вино | Активные с большим чеком |
| «Не забыть нужное» | Регулярный набор (молоко/хлеб/яйца) | Все активные |
| «Подготовиться к празднику» | Сезонные / праздничные наборы | По сезону + сегмент |

Подробнее по соответствиям сегмент↔категория: [[project_segment_to_category]].

## Как выбрать фреймворк (быстрая шпаргалка)

| Задача | Фреймворк |
|---|---|
| Короткий title пуша | [[hook-generator]] (не фреймворк) |
| Body пуша (1-2 фразы) | 4U |
| Описание акции (3-5 фраз) | FAB или AIDA |
| Длинный e-mail / лендинг | AIDA |
| Реактивация Спящих | PAS |
| Контентная сезонная | BAB |
| Выбор темы контентки | JTBD |
