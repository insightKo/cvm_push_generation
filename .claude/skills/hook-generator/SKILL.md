# Hook Generator — крючки для пушей и заголовков акций (Дикси-CVM)

## Когда применять
- Любая генерация **title пуша** (push notification headline) — лимит ~30 символов
- Заголовок **купона** / акции в карточке
- Subject e-mail / SMS в рамках CVM-кампании
- Контентная акция, где title тащит CTR

## Базовые принципы (must)
1. **Польза в первых 3 словах.** Не «Дорогой клиент, спешим сообщить» — а «Минус 30% на курицу».
2. **Цифра > прилагательного.** «Минус 25%» сильнее «огромная скидка».
3. **Конкретика > абстракции.** «На фарш Мираторг» > «на мясо».
4. **Запрет на «скидка»** — пиши «минус N%» ([[feedback_minus_discount]]).
5. **Не выдумывай факты** — не приписывать СТМ, не указывать цены, которых нет ([[feedback_no_fact_invention]]).
6. **Глагол действия** в первой части, если есть место: «Забери», «Получи», «Успей».
7. **Никаких эмодзи** в title, если бренд явно не разрешает.

## 7 рабочих паттернов крючков

| Паттерн | Когда | Пример |
|---|---|---|
| **Цифра + категория** | Категорийная акция | `Минус 30% на курицу` |
| **Дедлайн** | Ограниченная по времени | `До воскресенья — минус 25%` |
| **Бонус-валюта** | Монетные / баллы | `+200 монет за чек от 800₽` |
| **N за M** | Бандл / N+1 | `2 пачки кофе по цене 1` |
| **Вопрос → польза** | Реактивация | `Соскучились? Минус 15% на всё` |
| **Личное событие** | Триггерные | `Ваш любимый кофе — минус 20%` |
| **Сегмент-таргет** | Узкая категория | `Для ваших детей — минус 25%` |

## Анти-паттерны (никогда)
- ❌ «Внимание!», «Спешим сообщить», «Не пропустите»
- ❌ «Уникальное предложение», «Эксклюзив», «Только сегодня» (если это неправда)
- ❌ Восклицательные знаки в стопке (`!!!`)
- ❌ CAPS LOCK на всё слово
- ❌ Названия СТМ, которые не подтверждены данными
- ❌ Дублирование механики внутри недели ([[feedback_no_overlap_same_mechanic]])

## Чеклист перед выдачей
- [ ] ≤30 символов (или явный лимит проекта)
- [ ] Цифра / конкретика в первой половине
- [ ] Формулировка «минус N%», не «скидка N%»
- [ ] Категория совпадает с сегментом ([[feedback_segment_match_category]])
- [ ] Нет выдуманных фактов о SKU
- [ ] Нет дублирования с пушами этой же недели

## Процесс генерации
1. Возьми механику + категорию + сегмент.
2. Выбери 1-2 паттерна из таблицы, подходящих под сегмент:
   - Активные/Новые — цифра, бонус-валюта, N за M
   - Спящие/Отток — вопрос→польза, личное событие (реактивация, не награда за частоту — [[feedback_frequency_promos_segments]])
3. Сгенерируй 3-5 вариантов, отсортируй по силе хука.
4. Прогони через чеклист — выкини провалившие.
5. Верни топ-1 + 1 запасной.
