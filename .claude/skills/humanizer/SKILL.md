# Humanizer — очеловечивание текста (Дикси-CVM)

## Когда применять
- После генерации текста пуша / купона / описания акции
- Перед выдачей пользователю — финальный проход
- При жалобе «звучит как нейросеть»

## Стоп-слова и стоп-конструкции (вычищать всегда)

### Канцелярит / AI-маркеры
- «осуществлять», «производить», «являться»
- «в рамках», «в целях», «в части»
- «данный» (вместо «этот»), «вышеуказанный»
- «оптимальный», «инновационный», «уникальный»
- «решение» (в значении «продукт/акция»)

### Лишние усилители
- «по-настоящему», «действительно», «по сути», «в принципе»
- «огромный», «невероятный», «потрясающий»
- «приятно сообщить», «спешим порадовать»
- «не упустите шанс», «специально для вас» (если это шаблон на всех)

### AI-обороты-связки
- «стоит отметить, что…»
- «важно понимать, что…»
- «в современном мире…»
- «в нашем магазине вы найдёте…»

## Правила замен

| Было (AI) | Стало (человек) |
|---|---|
| Осуществить покупку | Купить |
| Получить возможность | Получить |
| В рамках акции | По акции / в акции |
| Данный товар | Этот товар / Эта позиция |
| Скидка составляет 30% | Минус 30% |
| Уникальное предложение для вас | Минус 30% на курицу до воскресенья |
| Спешим сообщить | (удалить вообще, начать с пользы) |
| Не упустите шанс | Успейте до Х |

## Принципы

1. **Глагол > отглагольное существительное.** «Купите» > «совершите покупку».
2. **Конкретика > обобщение.** «Курица Петелинка 1кг — 199₽» > «выгодные предложения на птицу».
3. **Короткая фраза > длинная.** Дроби предложения. Точка — друг.
4. **«Ты/вы» — как уже выбрано в бренде.** Дикси — «вы», но без официоза.
5. **Не извиняйся, не благодари без повода.** Это пуш, не письмо тёще.
6. **Запрет на «скидка»** — пиши «минус N%» ([[feedback_minus_discount]]).

## Тест на человечность
Прочитай вслух. Если хочется поморщиться, переписывай. Конкретные сигналы провала:
- Невозможно сказать на одном дыхании → дробить.
- Звучит как пресс-релиз → выкидывать связки.
- Можно вставить в любой бренд без правки → нет конкретики.
- Есть три прилагательных подряд → два убрать.

## Процесс
1. Прочитай текст.
2. Подсвети все стоп-слова из списка выше.
3. Замени по таблице или выкини.
4. Прочитай вслух. Сократи на 20-30%.
5. Проверь конкретику: есть ли цифра, категория, дедлайн.
6. Финальный чек: формулировка «минус N%», нет выдуманных фактов ([[feedback_no_fact_invention]]).
