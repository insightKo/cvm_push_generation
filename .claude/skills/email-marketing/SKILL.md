# Email/Push/CVM Marketing — сетка коммуникаций (Дикси)

## Когда применять
- Планирование сетки пушей/купонов на месяц
- Проверка: нет ли конфликта между акциями
- Назначение сегментов на категорию
- Распределение акций по декадам
- Проверка частоты «не больше N контактов в неделю»

## 1. Сегментация — соответствия категории ↔ аудитория

**Базовое правило:** аудитория категории, не аудитория темы ([[feedback_segment_match_category]]).

| Категория / товар | Сегменты | Почему |
|---|---|---|
| Coffee-to-go | Низкие сегменты + Случайные | Не «высокоценные», как кажется — реально это импульсники |
| Детские товары | Только Мамы | Узкая аудитория, не «все» даже на 1 сентября |
| Дачные / БВД | Широкие, БЕЗ Случайных | Нужна история покупок категории |
| Премиум-алкоголь | Активные с высоким чеком | Узкий сегмент |
| Базовая бакалея | Все сегменты | Универсальная категория |

Подробнее: [[project_segment_to_category]].

## 2. Сегменты ↔ механики

**Большой чек (>1500₽)** — прогр. кешбэк, бандлы, СТМ-Premium — **ТОЛЬКО Активные** ([[feedback_big_check_segments]]).
Спящим/Оттоку нужна **реактивация** (возврат, велкам-бонус), не рост чека.

**Частотные акции** (каскад «за N-ю покупку») — **только Активные/Новые** ([[feedback_frequency_promos_segments]]).
Спящим — реактивация, не награда за частоту.

**Монетные / «Дарим X монет»** — **только в первую декаду месяца** ([[feedback_coin_promos_timing]]).
Иначе монеты не успевают сгореть и конфликтуют между собой / с категорийными.

## 3. Частота и анти-конфликт

- **Не больше 1 механики на сегмент в неделю.**
  Не ставить однодневные «Все сегменты» с активацией 20% внутри недели парной акции с такой же механикой на смежной категории ([[feedback_no_overlap_same_mechanic]]) — клиент получает дубли, CTR падает.

- **Различать «Баланс баллов» и «Списание бонусов»** ([[feedback_balance_vs_writeoff]]):
  - «Баланс баллов» — регулярный сервисный пуш
  - «Списание бонусов» — акционный, под конкретную кампанию (Чёрная пятница и т.п.)
  - НЕ путать в одной сетке.

## 4. Структура цепочки CVM-кампании

```
1. Тизер (T-3 дня)  → лёгкое упоминание, без CTA
2. Анонс (T-0)      → основная механика, основной сегмент
3. Напоминание (T+2)→ дедлайн, "осталось X дней"
4. Last call (T-1)  → последний день, узкий сегмент
```

Между шагами 2 и 4 — **не больше одного дополнительного контакта** клиента по другим акциям.

## 5. Чеклист сетки на неделю / месяц

- [ ] У каждой акции механика подходит под сегмент (большой чек только Активные и т.д.)
- [ ] Категория соответствует сегменту
- [ ] Монетные/частотные — в первой декаде
- [ ] Нет дублей механик на смежных категориях в одну неделю
- [ ] «Баланс баллов» и «Списание бонусов» разведены
- [ ] Фильтр по месяцу в UI открывается на последнем месяце ([[feedback_month_filter_default]])
- [ ] Никакие SKU/цены не выдуманы ([[feedback_no_fact_invention]])
- [ ] В текстах — «минус N%», не «скидка» ([[feedback_minus_discount]])

## 6. Доставляемость / гигиена

- Не отправлять одинаковый title дважды подряд клиенту
- Если пуш = триггер от события (день рождения, день поиска товара) — приоритет выше планового
- Спящие → дозированно (1 раз в 7-10 дней, не каждый день)
- Отток → не больше 1 раза в 2 недели, иначе уходят в «заглушить»
