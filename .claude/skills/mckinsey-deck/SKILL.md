# McKinsey — структура и логика слайдов

Локальный скилл, кодирующий публичные принципы консалтинговых презентаций (Minto, MECE, action-titles). Не проприетарный материал — свод приёмов структурирования.

## Принципы
1. **Action title.** Заголовок слайда — это ВЫВОД целым предложением, а не тема. Не «Результаты», а «Сегментные акции дают ×7 доп. ТО на клиента». Читающий поймёт смысл по одним заголовкам.
2. **Пирамида Минто.** Сначала ответ/вывод, потом аргументы, потом данные. Сверху вниз: governing thought → ключевые линии → факты.
3. **MECE.** Декомпозиция без пересечений и без пропусков. Если 3 драйвера — они взаимоисключающие и вместе исчерпывающие.
4. **Один слайд — одно сообщение.** «So what?» формулируется явно. Если слайд не двигает аргумент — он лишний.
5. **Горизонтальный поток.** Процессы — слева направо, этапы-чевроны, стрелки. Время и причинность читаются по оси X.
6. **Количественная опора.** Каждый тезис подкреплён числом; под числом — источник и период. Не выдумывать цифры — только из данных; иначе плейсхолдер/вопрос.
7. **Ghost deck сначала.** Сторилайн (заголовки всех слайдов) собирается ДО оформления; колода должна «читаться по заголовкам».
8. **Консистентное кодирование.** Один цвет = один смысл во всей колоде (например: оранжевый — стратегия, фиолетовый — заведение, зелёный — выпуск/результат).

## Сторилайн (типовая последовательность)
1. Контекст/проблема → 2. Бизнес-кейс (сколько денег) → 3. Решение целиком (архитектура) → 4. Как это работает (процесс) → 5. Что нужно (ресурсы/агенты) → 6. Риски/контроль → 7. План по этапам с результатом на каждом.

## Чек-лист
- [ ] Колода читается по одним заголовкам и складывается в историю
- [ ] Каждый заголовок — вывод, не тема
- [ ] Декомпозиции MECE
- [ ] Под каждым числом — источник и период
- [ ] План описан через РЕЗУЛЬТАТ для бизнеса на каждом этапе, не через внутренние задачи
- [ ] На каждом слайде понятно «и что с того»
